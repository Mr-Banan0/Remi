# V75 / remi-0.2.9：证据卡保留主要原文

每张来源包以 `source_ids[0]` 指向主要来源。生成模型输入时，先保留主要来源，再按检索窗口、查询词重叠和时间选择辅助上下文。来源的角色标签、日期与原文继续保留。卡片中的 `source_ids` 对应实际展示的原文片段，模型可选的来源锚点随可见内容收敛。数据库仍完整保存全部来源。

旧排序会让关键词丰富的辅助回复挤掉主要原文。独立复现中，用户说周末中午前没有空，助手提供晨间学习建议；700 字节卡片只展示助手建议。三个回归测试在旧实现全部失败，修复后通过，覆盖短卡保留、不同角色一致处理、长卡保留上下文与预算边界。

真实 Jev 测试覆盖时间安排、设备兼容、预算、物品位置、前提核验和偏好，交换顺序重复，共 12 次。现有提示词与另一个效用提示词均为 12/12，因此保留现有提示词。加入长篇辅助上下文、使用生产卡片函数后，修复前后也均为 12/12：模型可以从摘要获得足够信息。本版的已验证收益是原文完整性，排序收益仍待查询边界快照重放验证。
