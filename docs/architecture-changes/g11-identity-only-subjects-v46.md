# V46：纯主体身份与关系记忆

日期：2026-10-26。实验 pipeline：`G11-identity-only-subjects-v46`。

## 主体阶段职责

主体模型接收当前原文、同会话最近一条上下文、关键词主体候选和身份依据，输出唯一字段 `subjects`。每个主体选择 create、reuse 或 pending，并可追加当前原文明确提供的名字、别名以及只适用于该主体的字面标签或角色。

程序校验主体类型、身份依据、别名和描述，生成稳定主体 ID 与本轮 P 句柄。主体阶段的 Prompt、JSON Schema、修正协议和提交路径均不包含 connections、关系语义或图边。

## 记忆阶段职责

记忆模型接收固定的主体 P 句柄和程序召回的记忆候选。持续关系、隶属状态及其他可持续命题写入 fact；关系的开始、变化或结束写入 event。记忆保存所有参与主体、来源、表达模式、时间和状态，图投影由记忆修订生成。

## 退出的路径

V45 的无类型主体 connection 已从模型输出、校验、修正、持久化和 Search 主体扩展中删除。该结构与 Fact／Event 重复表达同一联系，并让主体模型承担身份之外的职责。历史 V45 文档与提交保留用于实验复现，当前运行只有 V46 链路。

## 验收

- 主体输出 JSON 顶层只有 `subjects`。
- 主体 Prompt 不包含 connection、relationship、Fact、Event 或其他记忆维护规则。
- 主体提交只写主体记录，不写 endpoint_ids 图边。
- 关系原文由 Fact／Event 保存并选择全部参与主体。
- 沿用已有六个逻辑集合与 schema_version=13，不创建数据库表。
