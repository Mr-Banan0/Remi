# V33 独立实验：主体身份与无向连接

范围：验证主体模型仅维护身份并提出无向连接，原文中的任职、拥有、结束状态和愿望等由四类记忆提取保留。实验使用 MemoryStore，主 Add 维持 V32，已有数据库和旧实验保持原状。

新增 experiments/subject_connections.py：统一 subjects 合同沿用生产身份校验；connections 仅有 subject_refs 与 evidence.source_id。程序按用户与无序主体对生成稳定连接 ID，追加去重来源；未确认身份保持连接待定。关系方向、类型值、mode、操作选择和关系卡修订退出该实验合同。连接没有语义内容，原文通过来源保留。

保留 V32 的简洁文本输入与 12 组独立示例，新示例输出共用新合同，事实提取提示词明确接收关系陈述。新增协议和内存提交的离线测试，覆盖反向端点合并、来源去重、引用归属、自连接、待定与 few-shot 执行。

真实测试：相同 28 组和 10 组原文与主体候选，原主体身份和名称检查保持一致；连接按新语义评估无向主体对及证据，原方向、mode、更新操作要求退出。相同主体对的多个命题合并一条连接。meeting 新规则允许事件参与者建立连接，原扩展 Ada 样本的连接数量 0 要求放宽。该口径变化同样应用到 V32 输出重新评估，原旧得分另行保留。四组跨轮检查身份稳定及连接证据追加；三组真实四类记忆提取检查具体内容与表达状态保留。

冻结后运行一次，不根据本轮失败逐题改 prompt 重跑。结果明确区分身份能力变化与任务简化；最终报告记录主链路尚未接入该实验。
