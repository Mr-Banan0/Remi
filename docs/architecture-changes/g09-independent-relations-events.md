# G09 统一主体、五类关系、独立事件

## 当前方案与局部变更

完整流程及输入输出见 ../current-architecture.md。

| 部分 | G08 | G09 |
| --- | --- | --- |
| 身份 | GraphObject、来源别名 | 统一主体；增加名称／类型／生命周期历史 |
| 记忆 | 一般 Memory，修订附带断言与角色 | relation/event 两类独立维护记录；标签继续重叠 |
| 关系 | 一般实体 assertion 投影 | 五类索引、开放具体含义、独立命题与有效区间 |
| 事件 | 由标签、内容和附加角色表达 | 独立发生 ID、结构帧、计划／实际时间、状态与增量补丁 |
| 召回 | 跨标签主体召回 | 主体、五类关系、事件历史、全局与原文渠道 |
| 定稿 | 联合写内容与附加图字段 | 联合选择独立记录目标、字段补丁与联系判断 |
| 图 | involves/assertion/related | relation_endpoint、五类主体关系、participation、effect、event_link，加来源／修订边 |
| 搜索 | 混合召回与有界图扩展 | typed 卡片、一层主体关系及精确版本联系，动作日期与历史日期分开 |
| 旧数据 | G08 JSON | 新实验从原文重放，六表 SQL 保留 |

普通 Add 单元两次 GPT、空候选一次，共享一次输出修正；Search 一次 GPT、最多两步补搜与 Jev。模型、向量维度、证据计分规则和 Golden 输入沿用前版。

G08 生产模型、旧图字段及其专用测试被当前合同替代。删除原因是一般记忆上的附加断言无法独立维护关系有效期与事件发生身份。HTTP 调用和六表结构提供现有外部接口，历史报告由各自冻结代码解释。

## 完成标准

- 离线覆盖主体／关系／事件独立更新、角色保留、计划到完成、关系有效期、版本绑定、原子故障、历史时钟和实际六表重启。
- 真实预检保存全部尝试与失败；Golden 从独立冻结代码、同一输入和新六表库执行。
- 比较 G07、G08、G09 的严格原文证据 R@10、完整命中、全漏、MRR、逻辑 Add 及 Search 延迟；HTTP 尝试和物理供应商调用分开统计。
- 实际图导出检查悬空边与关系／事件结构，并保留语义 bad case。
