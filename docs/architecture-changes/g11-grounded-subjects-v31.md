# V31：先确认身份组，按来源复制证据

pipeline 为 `G11-grounded-subjects-v31`，正常主体阶段一次模型调用，四类记忆提取一次，共享最多一次协议修正。

## 修改与保留

- 主体和别名的模型证据改为 source_id。程序从当前提供的来源复制原文，保存现有 EvidenceRef、AliasEvidence 格式。关系继续输出准确原文摘录。
- reuse 先校验用户归属、可见 ID 与类型，再检查名称属于这个身份的已知名字或本轮有效新别名；证据可以使用这个身份的其他已知名字。已有规范名维持原样，固定主体视图携带召回别名，供记忆阶段理解回指。
- 新主体与待定称呼保留原文名称校验；未确认身份的记忆继续待定。新增别名的来源／名字失败单独审计，已确认身份与其他有效别名继续保留。
- prompt 按说话人归属、称呼分组、每组身份决策、主体联系四步组织，均在一次响应中完成。第一个英文示例为当前用户自我介绍，第二个为引用作者；其余示例覆盖明确不同的同名主体、歧义、动物别名、联系与事件边界。
- 模型输出中的旧主体／别名 quote 字段退出，原因是程序掌握原文并承担准确复制。内部已验证证据保留 quote，维持现有图和存储合同。
- 共用召回、关系修订、四类记忆追加、Search、schema_version=13 和既有六表沿用。检查点绑定 V31；旧实验使用各自冻结代码。

## 验证范围

先验证离线合同、已有别名引用、来源／用户／知识时间隔离、第一人称示例、身份与别名失败隔离及图一致性，再冻结代码。真实主体专项复用原28组单轮、4组跨轮输入，并增加新名字的同型样本。原完整通过指标保留，另分身份与名称覆盖、别名证据、关系和调用数。测试期间代码与prompt冻结，Golden保持停止。

## 验证结果

离线331项通过；真实主体单轮完整11/28、跨轮3/4，新名字同型4/10。主体身份与名称覆盖及具体未通过项见[真实验收报告](../subject-v31-results.md)。当前实现的程序合同已通过，主体语义与关系维护仍未形成完整闭环。
