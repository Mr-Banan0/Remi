# V28：关系专用，普通记忆分四类

## 统一说法

主体保存身份与别名；关系保存两个主体之间的联系；普通记忆保存事实、偏好、经验、事件。

| 普通记忆 | 代码类型 | 定义 |
| --- | --- | --- |
| 事实 | fact | 原文表达的信息、属性或状态，保留条件与时间范围 |
| 偏好 | preference | 原文表达的选择倾向、喜好或优先级 |
| 经验 | experience | 原文根据过往经历明确总结的教训、方法或结论 |
| 事件 | event | 一次发生或计划，保留状态、参与者与时间 |

具体的一次经历保存为事件；明确总结的认识保存为经验。计划属于事件的状态，持续状态属于事实内容。原文中的成立条件、表达模式和来源分别保留。

## 链路与改动

链路：共用召回 → 维护主体与关系 → 校验并固定身份 → 提普通记忆候选 → 维护定稿 → 原子提交。正常三次模型调用，所有阶段共享一次输出修正。召回沿用 V27，四类记忆共用候选池。

| 范围 | 改动 |
| --- | --- |
| 修改类型 | 普通创建限定 fact／preference／experience／event；持久类型另外保留 relation |
| 新增验收 | 四类与关系同时保存、索引、召回和重开；校验普通模型权限与关系端点 |
| 收敛关系 | relation 要求两个不同主体端点和来源证据；普通记忆通过参与者引用连接主体 |
| 修改验证 | 普通记忆阶段处理四类记忆与事件局部修改；关系操作由主体阶段处理 |
| 修改模型输入输出 | Prompt 给出四类定义，英文结构化 few-shot 覆盖四类；经验提取保留原文明确总结及其依据 |
| 修改检索与标签 | 保存实际类型，标签与索引保留 preference／experience；符合条件的非事件陈述进入热视图 |
| 退出旧逻辑 | 事实、偏好、经验统一折叠成 relation，以及所有非事件标签统一折叠成 fact |
| 保留 | 主体范围、别名证据、共用召回、事件生命周期、修订与原子提交、Search、Jev、六张物理表 |

事实、偏好、经验继续追加保存，保持已有内容时选择 keep。关系继续追加来源修订；事件继续局部修改计划日期、完成或取消状态。本轮实现分类与职责边界，普通陈述的语义失效与替换仍沿用已有行为。
