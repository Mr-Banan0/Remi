# V72 / remi-0.2.6：保留查询日期精度

Search 中只有月日、没有明确年份和来源锚点的日历表达，按月日从所有可见年份筛选。同一天跨年的结果保留各自日期，交给后续语义排序。显式完整日期保持精确过滤；相对日期沿用查询参考时间；来源锚定日期沿用来源时间。

只有月日的 before/after 表达保留为未解决的时间范围，执行既有无时间限制的补充检索。写入中的来源日期解析保持原规则。该版本复用既有英文和中文日历解析器，未增加数据集人物、日期、题目或答案规则；其他未支持格式继续走现有语义与修正路径。

premise_check 允许召回同日原文和未提供事件日期的事实、偏好、经验，使用 message_at 定位其观察日期；已有 event_at 优先。它提供核验材料，成立时间与观察时间仍分别保留在证据中。

替换的旧逻辑会把无年份的月日绑定到服务器当前年份；当库中只有历史资料时，可能把正确候选全部过滤掉。另一个退出的限制是 premise_check 只允许带 event_at 的文档进入时间范围。

验证：12 项新测试覆盖跨年同日、完整年份、中文日期、相对日期、闰日、无效日期、顺序关系未确定、观察时间及事件时间优先。全套 481 passed、11 skipped；API 版本另测。没有新增模型调用、数据库表或返回字段。收益由同库 Search 重放验证。
