# V70 / remi-0.2.4：Search 来源与日期协议

Planner 的 anchor_source_id 由 JSON Schema 限定为本轮展示的来源 ID。文档 ID 用于检索卡片，来源 ID 用于时间依据；程序在执行补搜前校验来源可见性。显式选定来源时，日期使用该来源正文及消息时间校验。省略来源时，日期使用查询及查询参考时间校验。

日期字段表达一个日期。日期区间完整保留在检索 query，time_expression=null、relation=independent，通过关键词与语义检索取得候选，交给后续排序。当前版本没有实现结构化区间过滤；这项协议测试的通过仅表示执行合法，不能代表区间召回完整。

字段描述与一个通用配送计数示例共同表达上述约定。退出的路径是：所有日期均要求出现在查询中，以及允许模型自由填写来源 ID。一次修正预算、Add、图扩展与 Jev 判断保持原样。
