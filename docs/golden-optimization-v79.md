# V79 / remi-0.2.13：独立查询的时间范围

独立合成测试覆盖工作安排、充电兼容、预算、证件、租约和宠物过敏。当前 Planner 会把助手建议当成后续查询目标；增加明确的条件延续示例可以改善查询内容，但仍频繁输出 `relation=independent, anchor_step=0`。仅增加说明或交换示例顺序仍未消除该行为。原始实验记录保存在 `/private/tmp/remi-plan-continuity*.json`。提示词试验暂未进入生产。

原编译器将这一组合传给时间召回；第一路结果只有一个日期时，第二路被限制到同日，多日期时转入锚点歧义退化。V79 使 independent 且无明确 time_expression 的查询使用完整可见历史，清空执行层的两个锚点字段。原模型决定保留在 trace；来源 ID 合法性校验继续执行。明确日期，以及 before / after / same_day 的时间连接保持原有处理。

这一改动只解释已有协议，不增加模型调用，不改变主体、写入、图结构或评分。测试包括独立查询访问后续日期证据、显式 after 保留先前结果锚点、来源与日期有效性。全套回归 509 项通过，随后新增的行为用例与锚点测试共 6 项通过。

完成标准是后续状态候选不被意外限制到旧日期，明确时间查询继续有效，并通过固定 Planner 记录的查询边界重放检查召回及排序变化。Golden 的题目与答案仅用于评估，生产逻辑依据查询协议执行。
