# V78 / remi-0.2.12：短证据卡保留指代上下文

证据卡先保留主要来源，再保留最相关的辅助来源。当预算可以容纳两段来源标题和每段至少 200 字节的原文空间时，卡片至少保留两段。逐段分配剩余预算，短原文节省的空间继续用于后续原文。总预算和最多八段来源的边界保持不变。

原实现按每段 500 字节估计数量，700 字节的 Planner 卡片只能选一段。V75 将主要来源排到第一后，“我选第二个”会保留，但解释第二个选项的上一条原文会消失。独立测试先复现缺失，再验证主要表达与选项解释同时保留、原文预算受控。该缺口解释了输入完整性的一个风险；它是否导致具体 Golden 退化仍由对照验证。

完整离线测试 503 passed；版本及 API 合同另验。本版沿用 V77 的原文重排，Add 与调用次数保持原样。后续使用 V74 查询前快照对比 V77，隔离证据卡预算分配的变化。
