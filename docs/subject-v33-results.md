## 实验实现与范围

模型输出 subjects（create／reuse／pending 与有来源的别名）和 connections。每个 connection 仅含两个 subject_refs 与 evidence.source_id。程序为已确认的无序主体对生成稳定 ID，合并重复连接、追加来源；未确认端点进入 pending；自连接、未知 ref、缺当前来源、外来来源被拦截。连接记录只有 id、owner、endpoint_ids、source_ids，原文保存在来源中。实验使用 MemoryStore，没有物理数据库或新表。

旧关系命题在测试输入中作为历史记忆证据显示，已有主体对显示为无向连接。输入原文及主体候选保持相同，提示词、示例返回与关系表达方式变化。事实提取提示明确接收任职、拥有、亲属等陈述，并保留 mode、归属、否定和原文条件。

此实验尚未接入主 Add 的原子写入、检索和持久化协议。主 src 与 V32 冻结版逐文件相同；该边界使本轮结果专门用于判断主体方案。独立实现位于 experiments/subject_connections.py；脚本位于 scripts/validate_subject_connections.py，评测要求留在脚本与实验数据中，主体决策函数读取原文与召回资料。
