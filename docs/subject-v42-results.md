## 尚存问题与 trace 归因

1. 两个英文重复活动输入中，模型除了正确的新活动，还输出了旧事件更新。旧项引用历史来源，缺少本轮依据，被程序拦截；有效新项继续保存。一组主体修正先用掉共享额度，因此记忆阶段直接拒绝无效项。这是模型当前来源范围控制问题。
2. 固定回归的一轮主体输出把旧事件描述挂到本轮来源，主体校验拒绝无效描述；主体 ID 仍正确复用。主体维护沿用现有设计，该问题仍需独立评估。
3. 事件更新正文有时丢失原有细节，例如取消后的正文只写“取消了那次摄影课”，早前环节保留在旧修订和来源中。当前图与版本保留证据，完整当前叙述的语义仍不稳定。
4. 新场景英文第二次活动输出含正确日期正文，但 time_expression=null，结构化 planned_at 仍为空。当前检查能拦截无依据的错误日期，模型遗漏的结构字段仍有缺口。

两处程序问题已依据通用规则修复并回归：允许经来源和消息日期验证的等价日期表达；检查正文中的完整日期是否有依据，避免正文错误年份与结构日期并存。保留“下午”等时间精度信息。相关规则覆盖通用日期形式，运行时没有实验人物、样本答案或数据集特判。
