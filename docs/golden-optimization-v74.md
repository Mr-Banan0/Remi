# V74 / remi-0.2.8：来源包保留完整检索目的

同一主要原文支持多条记忆时，Search 把这些记忆合成一个候选来源包。来源包同时保留各条已召回记忆的角色与具体查询目的，供 Jev 判断原问题所需的证据。

旧实现只从包的代表记忆读取角色与目的。例如直接答案记忆成为代表后，同原文中的限制记忆虽然还在正文里，constraint 目的却会丢失。新实现先按主要来源归集已召回目的，再将完整集合交给代表候选。不同来源保持各自目的集合。

两项测试覆盖角色完整保留、具体查询完整保留、不同来源隔离及输入集合不变。第一项先在旧实现复现失败。全套 487 passed、11 skipped，API 版本另测。Jev 继续决定排名，本版没有增加强制保留的名额或新的模型调用。

V74 汇集 V71 的维护身份说明、V72 日期精度、V73 逻辑排名和本次来源包修复，使用统一运行版本。后续完整 Golden 保存查询前快照，便于按原始可见数据重放 Search。
