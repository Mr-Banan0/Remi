# V69 / remi-0.2.3：图扩展预算

图种子按已有检索顺序进入最多24条的入口集合。每个原文命中可激活相关记忆；相同入口去重。邻居使用独立的最多24条候选预算，再由既有 graph_limit 限制输出。

邻居先按关键词和向量融合相关性排序，缺少直接分数时按其入口排名排序。内部ID仅作为并列时的确定性排序依据。最终候选仍进入全局RRF和Jev，保留原有图通道权重与API返回协议。程序使用已有向量，没有增加模型调用。

退出逻辑：种子与邻居共用24个名额、先按内部ID裁剪种子及邻居。旧逻辑会在入口数达到24时完全停止相关边扩展，并可能在评分前丢弃最相关的邻居。

验证：新增两个测试先在旧实现复现失败，分别覆盖24个种子挤占全部邻居预算、最相关入口因ID顺序被裁掉；修复后通过。另增加高连接度节点按相关性选择邻居的测试。最终全套466 passed、11 skipped。
